# ARC — Interaction and Visual Rules

## Spatial model

- Calendar/planner is centered and visually dominant.
- Environmental background is distinct from Arc paper.
- No persistent left navigation rail.
- Settings opens outward from the left edge.
- Fridge opens outward from the right edge.
- Task Bar rises from the bottom edge.
- Furniture does not overlay, shrink, squeeze, shift, or reflow the approved calendar geometry.
- Opening multiple furniture surfaces remains coherent and unclipped.

## Calendar

- Default Week is Monday–Friday.
- Optional weekends may show Sunday–Saturday; Sunday is first when enabled.
- Year Map has no weekends and every week begins Monday.
- Today, no-school, early-release, selected, focused, and instructional states must be visually distinct and not rely on color alone.
- Day carries unresolved continuity first, then today's plan.

## Object grammar

- Unit: circular magnet.
- Lesson: paper/sticky-note form.
- Note/Idea: a distinct lightweight paper object.
- Selecting an object opens a contextual pop-up toolbar.
- Capability depth follows the object between surfaces without data loss.
- Shallow surfaces hide advanced fields but provide Full Edit.

## Core furniture

- Fridge Door is finite, persistent staging. Overflow moves to Drawer; never auto-evict the oldest item.
- Drawer is findable storage, not a second planner.
- Task Bar contains Must/Should/Could and accepts canonical Notes only.
- Clean Up closes/collapses surfaces; it never deletes, archives, schedules, reprioritizes, reparents, or changes saved positions.

## Visual system

- Paper: `#F3EBDD`; Ink: `#2C2E2E`.
- Warm anchors: Mustard `#E4B33D`, Terracotta `#C96845`.
- Principal cool counterweight: Dusty Blue `#7C9CAD`.
- Support: Sage `#9AAA89`, Dusty Pink `#C99A9E`, Lavender `#AAA0B8`, Kraft `#C6A77D`, Soft Charcoal `#4A4945`.
- Use the supplied `tokens.css` as the starting token file.
- 4 px spacing base; 4/8/12/16/24/32/48/64 scale.
- Utility radius near 8 px. Avoid all-rounded containers and pillification.
- Primary UI: adult rounded humanist sans. Editorial serif only for selected statements/headings. Handwriting only for short accents.
- Matte thin paper, restrained edge irregularity, dry wax/pastel marks, and subtle page depth.
- No glassmorphism, glossy 3D, clay/plastic icons, literal desk scenes, thick paper stacks, or craft-store decoration.

## Motion

Motion explains cause and effect: slide, shift, tuck, fold, pin, draw. No bouncing, sparkle, celebration loops, or game-like reward motion. Honor reduced motion.

## Language

Use concrete verbs: move, continue, shift, fix, hold, place, teach, review, return. Avoid generic productivity language, motivational coaching, childish teacher phrasing, or claims that Arc is the teaching expert.
