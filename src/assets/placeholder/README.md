# Arc Batch 1 placeholder contract

These are temporary CSS placeholders for the approved Batch 1 tactile asset families. They exist so page geometry and interaction can be built before final PNG/WebP masters arrive.

Replace, do not redesign, when final assets are available:

- planner paper / open-planner anatomy
- binding anatomy
- surrounding field
- Fridge metal
- Fridge pull
- Settings yellow folder/tab
- Task Bar ledge
- Unit circular magnet
- Lesson square paper
- Idea/Note lighter paper family
- Important red-circle family
- Year graphite-X family
- Arc mark where a final master supersedes the current mark
- material swatches / restrained collage accents

Rules:
1. Placeholder dimensions belong to layout; texture belongs to the asset.
2. Final assets must not change canonical calendar geometry.
3. Keep text-bearing centers quiet and high contrast.
4. Do not use collage as filler. Accents earn placement by reinforcing physical hierarchy or continuity.
5. Preserve semantic HTML and non-drag paths when swapping assets.
6. Do not flatten text into image assets.
